Документация HPP и WHP

HPP (Hardware Performance Programming) — это интерпретируемый язык программирования для консольных и оконных приложений. WHP (Web Hardware Programming) — расширение для разработки статических веб-страниц.

Скачать установщик (.EXE)

Введение и использование файлов

Оба языка предлагают мощные команды для работы с переменными, математическими операциями, условиями и многим другим.

  • Файлы для консольных приложений должны иметь расширение .hpp.
  • Файлы для веб-разработки должны иметь расширение .whp.

Компиляция и запуск

Чтобы сделать исполняемый файл из .hpp, напишите в консоли:

hppinstaller <полный путь к папке с файлом (без слеша в конце)> <имя файла.vvm>

Скрипт создаст папку, важную для работы программы, и исполняемый батник, запускающий скрипт на ОС, где может быть не установлен HPP (важно, чтобы файл и батник были в одной директории).

Запустить скрипт можно через IDE или через консоль Windows:

hpp <полный_путь_к_файлу.hpp>

Это действие создаст файл с таким же именем, но расширением .vvm, который сможет обработать интерпретатор.

vvm <полный_путь_к_файлу.vvm>

Это действие запускает скрипт. Также можно открыть с помощью C:\windows\system32\hpp.exe для .hpp или с помощью C:\windows\system32\vvm.exe для .vvm.

Команды для консольного приложения (HPP)

Переменные и типы данных

Объявление переменных и базовые манипуляции с ними:

str name = "текст"
int number = 10
float f_number = 10.5

str words = split %переменная%
int random_val = Random 1 100
float random_f = Random 1.0 10.0

Ввод и вывод

System.ReadLine()
System.ReadInt()
System.out.print Привет, мир!
System.timeout 5

Работа с реестром Windows

System.reg.read HKEY_CURRENT_USER Software\MyApp MySetting var_name
System.reg.write HKEY_CURRENT_USER Software\MyApp MySetting REG_SZ "MyValue"
System.reg.delete HKEY_CURRENT_USER Software\MyApp MySetting

Базы данных SQLite

DB.open my_database.db
DB.execute CREATE TABLE users (id INTEGER, name TEXT)
DB.commit
DB.query SELECT * FROM users res_array
DB.close

Управление файлами

System.create.file "path"
System.delete.file "path"
System.file.read "path" target_var
System.edit.file "path" : новый контент
System.add_new_line_edit.file "path" добавляемая строка

Математика и Массивы

System.calc %переменная% + 5
int result = #res#

Math.factorial %num% res_var
Math.sqrt 16 res_var

array my_arr = []
array add my_arr "значение"
array get my_arr 0 target_var
array print my_arr

Ассоциативные массивы (Map)

map my_map = {}
map add my_map key value
map key my_map key target_var
map.haskey my_map key : System.out.print Ключ найден!

Конвертация типов

Если вы хотите конвертировать float в int или наоборот, используйте вычитание нуля:

int integer = %float% - 0
float float_val = %integer% - 0

Оконные приложения (GUI)

Интерфейс строится внутри логических блоков функций. Пример реализации окна Калькулятора:

public static void Main(String[] args) {
    System create window Calculator 200 200
    System add_text window Calculator 10 10 Enter first number
    System get window Calculator fn 60 20 20 30
    
    System add_text window Calculator 10 45 Enter second number
    System get window Calculator sn 60 20 20 65
    
    System add_text window Calculator 10 80 Enter sing + - * / :
    System get window Calculator si 50 20 20 100
    
    str p = "+"
    str m = "-"
    str y = "*"
    str r = "/"
    
    if %si% == %p% : int result = %fn% + %sn%
    if %si% == %p% : System out print %result%
    
    if %si% == %m% : int result = %fn% - %sn%
    if %si% == %m% : System out print %result%
    
    if %si% == %y% : int result = %fn% * %sn%
    if %si% == %y% : System out print %result%
    
    if %si% == %r% : int result = %fn% / %sn%
    if %si% == %r% : System out print %result%
    
    System add_text window Calculator 10 120 Result
    System add_text window Calculator 60 120 %result%
}

Дополнительные команды управления элементами GUI:

System.add_button.window Окно Текст X Y W H Имя_Функции
System.clear.window Окно

Команды для веб-разработки (WHP)

Позволяет структурировать и собирать разметку, стили и исполняемые скрипты внутри единого текстового пространства.

Основные дескрипторы

  • <WHP> — указывает начало WHP файла.
  • <WHP_END> — указывает конец WHP файла.
  • HTML <контент> — добавляет HTML-контент в тело веб-страницы.
  • CSS <стили> — добавляет стили на веб-страницу.
  • JS <скрипт> — добавляет JavaScript код.
  • PRINT <сообщение> — выводит сообщение на странице через JS-механизм.

Пример файла .whp

<WHP>
HTML <h1>Добро пожаловать на мой сайт!</h1>
CSS body { font-family: Arial, sans-serif; background-color: #f0f0f0; }
JS console.log("Страница загружена.");
PRINT Привет, мир!
<WHP_END>
